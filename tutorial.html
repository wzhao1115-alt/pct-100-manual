第一步：开发环境搭建

配置 Arduino IDE 与 ESP32-C3 开发板支持

1

安装 Arduino IDE

从 Arduino 官网下载最新版 IDE（建议 2.x 以上版本），完成安装后启动。

2

添加 ESP32 开发板管理器

打开 文件 → 首选项 → 附加开发板管理器网址，添加以下 URL：

https://espressif.github.io/arduino-esp32/package_esp32_index.json
3

安装 ESP32 平台

打开 工具 → 开发板 → 开发板管理器，搜索 esp32，安装 esp32 by Espressif Systems（版本 3.3.8）。

4

配置开发板参数

参数设置值
BoardESP32C3 Dev Module
USB CDC On BootEnabled
CPU Frequency160 MHz
Flash Size4 MB
Upload Speed921600（失败时可降至 115200）

第三步：编译与上传

使用 Arduino IDE 或命令行工具完成固件下载

1

打开工程

在 Arduino IDE 中打开 PCT-100.ino 主文件。确认左侧工程目录中包含 key.cpp、exti.cpp、relay.cpp 等模块文件。

2

选择开发板和端口

工具 → 开发板 → ESP32C3 Dev Module。通过 USB 连接实训板，在 工具 → 端口 中选择对应的 COM 口。

3

编译项目

点击 验证（✓） 按钮或使用命令行：

arduino-cli compile -b esp32:esp32:esp32c3:CDCOnBoot=cdc D:\桌面\file\PCT-100
预期结果：编译通过，Sketch 占用约 23% 程序空间和 4% 动态内存。
4

上传固件

点击 上传（→） 按钮或使用命令行：

arduino-cli upload -b esp32:esp32:esp32c3:CDCOnBoot=cdc -p COM3 D:\桌面\file\PCT-100
下载失败？尝试按住 BOOT 键后点击下载，开始下载后松开 BOOT 键。或降低 Upload Speed 至 115200。

第四步：功能验证

逐一验证 PCT-100 各项功能是否正常

1

串口输出检查

打开串口监视器（波特率 115200），复位后应看到 "PCT-100 自动模式启动"

2

总开关验证

KEY1 关闭时灯泡和风扇必须断开。KEY1 打开后系统开始运行

3

自动模式验证

默认自动模式。温度 ≥ 30°C 时风扇自动开启；温度 ≤ 28°C 时关闭

4

光照控制验证

遮挡光敏传感器使 ADC ≤ 1700 时灯泡熄灭；强光照射使 ADC ≥ 1900 时灯泡点亮

5

手动模式验证

长按 KEY2 1.5 秒进入手动模式，短按 KEY2 循环切换灯泡/风扇状态：00→01→10→11→00

6

模式切换验证

长按 KEY2 1.5 秒可在自动/手动模式间切换，松手不应触发短按

常见问题 FAQ

遇到问题时请先查阅以下解答

按键没有反应怎么办？
  • 检查 KEY_PIN 是否与硬件原理图一致（KEY1=GPIO20, KEY2=GPIO21）
  • 确认 exti_init() 在 setup() 中被正确调用
  • 检查按键硬件连接是否良好
LED 出现多次翻转（按一次触发多次）？

适当增大 KEY_DEBOUNCE_MS（例如从 20ms 改至 30ms），或检查按键线缆是否过长或接触不良。

串口监视器没有输出？
  • 确认开发板设置中 USB CDC On Boot = Enabled
  • 确认串口监视器波特率设为 115200
  • 确认选择了正确的 COM 端口
下载失败（A fatal error occurred）？
  • 按住 BOOT 键后点击下载，开始下载后松开 BOOT 键
  • 降低 Upload Speed 至 115200
  • 检查 USB 数据线是否支持数据传输（非仅充电线）
  • 尝试更换 USB 端口或重启电脑
编译报错 "OneWire.h: No such file or directory"？

缺少 OneWire 库。在 Arduino IDE 中打开 工具 → 管理库，搜索 OneWire 并安装。DS18B20 传感器还需要 DallasTemperature 库。

如何确认当前处于自动模式还是手动模式？

观察串口监视器输出。每次模式切换时会打印 "进入自动模式" 或 "进入手动模式"。手动模式下短按 KEY2 也会输出当前继电器状态。
