K

key 模块 — 按键消抖状态机

实现完整的非阻塞按键状态机，支持短按/长按事件识别。每次 key_task() 调用仅做少量判断，不包含任何阻塞操作。

函数功能说明
key_init()初始化按键 GPIO配置 INPUT_PULLDOWN，读取初始状态
key_start_debounce(id)启动消抖定时器使用 millis() 记录当前时间
key_task()消抖状态机轮询每轮 loop() 调用，检查消抖完成
key_get_event(id)获取按键事件返回 SHORT_PRESS / LONG_PRESS / NONE
key_scan(id)兼容旧接口内部调用 key_task()，返回 PRESSED/RELEASED
C++ 
// 非阻塞消抖核心逻辑（简化版）
void key_task(void) {
    unsigned long now = millis();
    for (uint8_t i = 0; i < KEY_COUNT; i++) {
        // 检测引脚变化，启动消抖
        if (key_stable_state[i] == KEY_RELEASED && digitalRead(key_pins[i]) == HIGH)
            key_start_debounce(i);

        // 消抖时间到达，确认状态
        if (key_debounce_active[i] && (now - key_debounce_start[i] >= KEY_DEBOUNCE_MS)) {
            key_debounce_active[i] = 0;
            uint8_t current = (digitalRead(key_pins[i]) == HIGH) ? KEY_PRESSED : KEY_RELEASED;
            if (current != key_stable_state[i]) {
                key_stable_state[i] = current;
                if (current == KEY_PRESSED) key_press_start[i] = now;
                else key_event[i] = KEY_EVENT_SHORT_PRESS;  // 松手时生成短按事件
            }
        }
        // KEY2 长按检测（1.5s）
        if (i == KEY2_ID && key_stable_state[i] == KEY_PRESSED)
            if (now - key_press_start[i] >= KEY2_LONG_PRESS_MS)
                key_event[i] = KEY_EVENT_LONG_PRESS;
    }
}
E

exti 模块 — 外部中断管理

管理按键的硬件中断绑定。ISR 使用 IRAM_ATTR 修饰放置在 IRAM 中，执行时间极短（仅设置一个 volatile uint8_t 标志位），确保中断响应延迟最小。

C++ 
// exti.h — 中断标志位声明
extern volatile uint8_t key1_int_flag;
extern volatile uint8_t key2_int_flag;

void exti_init(void);
void IRAM_ATTR key1_isr(void);
void IRAM_ATTR key2_isr(void);

// exti.cpp — ISR 实现（仅置标志位）
volatile uint8_t key1_int_flag = 0;
volatile uint8_t key2_int_flag = 0;

void exti_init(void) {
    key_init();
    attachInterrupt(digitalPinToInterrupt(KEY1_PIN), key1_isr, RISING);
    attachInterrupt(digitalPinToInterrupt(KEY2_PIN), key2_isr, RISING);
}

void IRAM_ATTR key1_isr(void) { key1_int_flag = 1; }
void IRAM_ATTR key2_isr(void) { key2_int_flag = 1; }
设计原则：ISR 中禁止使用 delay()、Serial.print() 等阻塞或耗时操作。所有业务逻辑在 loop() 中通过查询标志位完成，这是嵌入式实时系统的核心编程规范。
R

relay 模块 — 继电器输出管理

提供灯泡和风扇两路独立输出控制，支持单独操作和位组合操作。使用宏定义将逻辑名称映射到物理引脚，方便硬件变更时快速适配。

函数功能
relay_init()初始化两路继电器 GPIO 为 OUTPUT，默认断开
lamp_power_set(on)单独控制灯泡（GPIO6）
fan_power_set(on)单独控制风扇（GPIO7）
usb_power_set_state(state)按位组合控制（bit0=灯泡, bit1=风扇，支持 00/01/10/11 四状态）
usb_power_get_state_bits()读取当前继电器状态位

主循环任务调度

loop() 中的任务调度策略 — 所有操作非阻塞、周期性轮询

图 2：主循环任务调度流程 — 每轮 loop() 依次执行中断标志检查、按键任务、传感器采集、控制逻辑，无阻塞

关键约束：所有周期性任务的总执行时间远小于 1ms，系统始终保持实时响应能力。即使按键消抖期间，传感器采集和继电器控制也不受影响。
