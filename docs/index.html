了解产品 快速入门

产品概述

PCT-100 是一款面向化工自动化教学的实训平台，帮助学员掌握嵌入式控制、传感器采集与过程自动化核心技能

⚙

双模式控制

支持自动模式（传感器驱动）和手动模式（按键控制）两种运行方式，灵活适配不同教学场景

🌡

温度采集与控制

板载 DS18B20 数字温度传感器，精度 ±0.5°C，自动模式下根据温度阈值控制风扇启停

☀

光照检测

光敏传感器 ADC 采集，自动模式下根据环境光照强度控制灯泡开关，支持阈值可配置

⚡

继电器输出

两路独立继电器输出通道，分别控制灯泡和风扇，输出 HIGH 吸合、LOW 断开，支持位状态组合控制

✈

非阻塞按键消抖

基于 millis() 状态机的非阻塞消抖算法，中断服务函数极简设计，主循环不受按键处理阻塞

🔌

ESP32-C3 主控

搭载 RISC-V 32 位处理器，160MHz 主频，4MB Flash，支持 Wi-Fi 与 BLE 无线通信扩展

运行模式对比

🌡 自动模式（默认）

系统上电后默认进入自动模式。KEY1 为总开关，打开后系统自动读取传感器数据：

  • 温度 ≥ 30°C 开风扇，≤ 28°C 关风扇
  • 光敏 ADC ≥ 1900 开灯泡，≤ 1700 关灯泡
  • KEY2 短按无效，长按 1500ms 切换至手动模式

🔧 手动模式

长按 KEY2 1500ms 从自动模式切入手动模式：

  • KEY2 短按切换灯泡/风扇状态
  • 状态循环：00 → 01 → 10 → 11 → 00
  • 第一位代表灯泡，第二位代表风扇
  • 长按 KEY2 1500ms 切回自动模式

✓

中断与主循环分离

ISR 中仅 flag = 1，IRAM_ATTR 修饰确保快速响应，避免中断嵌套和优先级反转

🕑

非阻塞任务调度

所有周期性任务（按键扫描、传感器采集）均基于 millis() 时间比较，无 delay() 调用

🔒

安全互锁设计

KEY1 总开关关闭时硬件级切断继电器，防止自动/手动模式切换时的异常输出
